# PresentPerfect — Магазин идеальных подарков

Краткое описание: Интерактивный лендинг для подбора подарков с помощью встроенного квиза на чистом JavaScript. На сайте реализована адаптивная верстка, рабочая форма обратной связи и динамическая генерация результатов теста.

## Ссылка на проект (Netlify)
[Посмотреть сайт].present-perfect-shop.netlify.app.

## Инструкция по локальному запуску
1. Скачайте файлы проекта или клонируйте репозиторий:
   `git clone <ссылка-на-ваш-репозиторий>`
2. Откройте файл `index.html` в любом современном браузере (например, двойным щелчком мыши или через Live Server в VS Code).
3. Для работы формы требуется активное интернет-соединение.
